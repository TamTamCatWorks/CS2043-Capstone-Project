# Auction Feature Delegation

## Branching
Everyone will implements some parts of the`api`:
```
api/
├── api/item-service      ← Loc
├── api/auction-service   ← Kien
└── api/feature/bid-service       ← Dai
```

## General Notes

### Cookie Session (Postman)
We use Spring Session (cookie-based) for authentication. To test protected endpoints in Postman:

1. Send `POST /users/login` with your credentials
2. Postman automatically stores the `JSESSIONID` cookie
3. All subsequent requests in the same collection will send the cookie automatically
4. Go to **Cookies** tab in Postman to verify `JSESSIONID` is present
5. If you get `403 Forbidden`, your session has expired — login again

### Error Response Format
All errors return:
```json
{
  "timestamp": "2026-05-06T10:00:00",
  "status": 404,
  "error": "Not Found",
  "message": "Item not found."
}
```

### Exception Handling
Do NOT throw HTTP-specific exceptions — throw standard Java exceptions, `GlobalExceptionHandler` in `api` maps them:

| Exception | HTTP Status |
|---|---|
| `IllegalArgumentException` | 400 Bad Request |
| `NoSuchElementException` | 404 Not Found |
| `IllegalStateException` | 409 Conflict |

## Design — Extensible Item Creation

Instead of separate endpoints and DTOs per item type, we use a single `ItemRequest` with a `details` map and a factory pattern in `ItemService`. Adding a new category only requires adding a new `ItemCreator` — nothing else changes.

### `api/dto/ItemRequest.java`
```java
public record ItemRequest(
    String name,
    String description,
    double startingPrice,
    ItemCondition condition,
    String sellerId,
    String itemType,             // "ART", "ELECTRONICS", "VEHICLE"
    Map<String, Object> details  // type-specific fields
) {}
```

### `api/dto/CreateAuctionRequest.java` — combined seller form
```java
public record CreateAuctionRequest(
    String title,
    LocalDateTime startTime,
    LocalDateTime endTime,
    ItemRequest item             // item nested inside auction request
) {}
```

### Why two endpoints?

```
POST /auctions                  ← seller flow, creates item + auction in one form
POST /auctions/existing-item    ← admin/advanced flow, auction for existing item
POST /items                     ← standalone item creation
```

`POST /auctions` is the main seller flow — one form, one request, both item and auction created atomically via `@Transactional`. If item creation fails, auction doesn't get created either.

### What to build

**`service/auction/item/ItemCreator.java`** — base class:
```java
public abstract class ItemCreator {

    public Item create(ItemRequest req, User seller) {
        validate(req);
        return buildItem(req, seller);
    }

    protected abstract Item buildItem(ItemRequest req, User seller);

    protected void validate(ItemRequest req) {
        if (req.name() == null || req.name().isBlank())
            throw new IllegalArgumentException("Item name is required.");
        if (req.details() == null)
            throw new IllegalArgumentException("Item details are required.");
    }

    protected String get(Map<String, Object> details, String key) {
        Object val = details.get(key);
        if (val == null) throw new IllegalArgumentException("Missing field: " + key);
        return val.toString();
    }

    protected int getInt(Map<String, Object> details, String key) {
        Object val = details.get(key);
        if (val == null) throw new IllegalArgumentException("Missing field: " + key);
        return ((Number) val).intValue();
    }

    protected boolean getBoolean(Map<String, Object> details, String key) {
        Object val = details.get(key);
        if (val == null) throw new IllegalArgumentException("Missing field: " + key);
        return (Boolean) val;
    }
}
```

**`service/auction/ItemService.java`:**
```java
@Service
public class ItemService {

    private final ItemRepository itemRepository;
    private final UserRepository userRepository;
    private final Map<String, ItemCreator> registry;

    public ItemService(ItemRepository itemRepository, UserRepository userRepository) {
        this.itemRepository = itemRepository;
        this.userRepository = userRepository;
        this.registry = Map.of(
            "ART",         new ArtCreator(),
            "ELECTRONICS", new ElectronicsCreator(),
            "VEHICLE",     new VehicleCreator()
        );
    }

    @Transactional
    public Item create(ItemRequest req) {
        User seller = userRepository.findById(req.sellerId())
            .orElseThrow(() -> new NoSuchElementException("Seller not found."));
        ItemCreator creator = registry.get(req.itemType());
        if (creator == null)
            throw new IllegalArgumentException("Unknown item type: " + req.itemType());
        return itemRepository.save(creator.create(req, seller));
    }

    @Transactional(readOnly = true)
    public Item findById(String id) {
        return itemRepository.findById(id)
            .orElseThrow(() -> new NoSuchElementException("Item not found."));
    }
}
```


**`api/controller/ItemController.java`:**

```java
@Service
public class AuctionService {

    private final AuctionRepository auctionRepository;
    private final ItemService itemService;
    private final UserRepository userRepository;

    // main seller flow — creates item and auction atomically
    @Transactional
    public Auction createWithItem(String sellerId, CreateAuctionRequest req) {
        Item item = itemService.create(req.item());
        User seller = userRepository.findById(sellerId)
            .orElseThrow(() -> new NoSuchElementException("Seller not found."));
        return auctionRepository.save(new Auction(req.title(), seller, item,
            req.item().startingPrice(), req.startTime(), req.endTime()));
    }

    // advanced flow — auction for an already existing item
    @Transactional
    public Auction create(String sellerId, String itemId, String title,
                          double startingPrice, LocalDateTime startTime, LocalDateTime endTime) {
        User seller = userRepository.findById(sellerId)
            .orElseThrow(() -> new NoSuchElementException("Seller not found."));
        Item item = itemService.findById(itemId);
        return auctionRepository.save(new Auction(title, seller, item,
            startingPrice, startTime, endTime));
    }
```

## Dai - Bid Service
**Branch:** `feature/bid-service`

### What to build

**`service/auction/BidService.java`:**
```java
@Service
public class BidService {

    @Transactional
    public BidTransaction placeBid(String auctionId, String bidderId,
                                   double amount, BidTransaction.BidType bidType) {
        Auction auction = auctionRepository.findById(auctionId)
            .orElseThrow(() -> new NoSuchElementException("Auction not found."));
        User bidder = userRepository.findById(bidderId)
            .orElseThrow(() -> new NoSuchElementException("Bidder not found."));

        if (!auction.isAcceptingBids())
            throw new IllegalStateException("Auction is not accepting bids.");
        if (!auction.isValidBidAmount(amount))
            throw new IllegalArgumentException("Bid amount too low.");
        if (bidder.getBalance() < amount)
            throw new IllegalArgumentException("Insufficient balance.");

        BidTransaction tx = new BidTransaction(auction, bidder, amount, bidType);
        auction.recordBid(tx);
        auctionRepository.save(auction);
        return bidRepository.save(tx);
    }

    @Transactional(readOnly = true)
    public List<BidTransaction> findByAuction(String auctionId) { ... }

    @Transactional(readOnly = true)
    public List<BidTransaction> findByBidder(String bidderId) { ... }
}
```

**Add to `api/controller/AuctionController.java`:**
```java
// bidderId comes from session, not request body
@PostMapping("/{id}/bids")
public ResponseEntity<BidResponse> placeBid(@PathVariable String id,
                                             @RequestBody BidRequest req,
                                             HttpSession session) {
    String bidderId = (String) session.getAttribute("userId");
    return ResponseEntity.status(HttpStatus.CREATED).body(BidResponse.from(
        bidService.placeBid(id, bidderId, req.amount(), req.bidType())
    ));
}

@GetMapping("/{id}/bids")
public ResponseEntity<List<BidResponse>> getBids(@PathVariable String id) {
    return ResponseEntity.ok(bidService.findByAuction(id)
        .stream().map(BidResponse::from).toList());
}
```

**`api/dto/BidRequest.java`** — no bidderId, comes from session:
```java
public record BidRequest(double amount, BidTransaction.BidType bidType) {}
```

### Important Notes
- `bidderId` comes from session — never trust client-provided identity
- `@Version` on `Auction` handles race conditions — always use `@Transactional`
- Three checks before placing bid: auction accepting, amount valid, balance sufficient

## Reference — Module Structure
```
auction-system/
├── model/      ← domain entities, no framework dependencies
├── persist/    ← repositories only
├── service/    ← business logic, throws standard Java exceptions
└── api/        ← controllers, DTOs, security, entry point
```

Dependency flow:
```
api → service → persist → model
```
